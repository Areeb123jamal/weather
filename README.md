# Exploratory Data Analysis: Weather & Supermarket

This repository contains two Jupyter Notebooks exploring different datasets: weather data and supermarket data.

## Projects

### Weather Analysis
Notebook: `Weather Analysis.ipynb`

Use this notebook to review the data preparation, exploratory analysis, and visualizations included in the weather analysis.

### Supermarket Analysis
Notebook: `Supermarket Analysis.ipynb`

Use this notebook to explore supermarket data and inspect the analysis and visualizations included in the notebook.

## Tools
- Python
- Jupyter Notebook
- Pandas and visualization libraries, where used in the notebooks

## How to explore
1. Open either notebook directly on GitHub, or clone the repository and run it in Jupyter.
2. Review the dataset fields and any data-cleaning steps.
3. Run the notebook cells in order to reproduce the analysis.
4. Verify charts and conclusions against the data before sharing results.

## Portfolio improvements
For a more reproducible analysis, add the dataset source, environment/dependency file, definitions of key fields, and a concise summary of verified findings. This README does not claim specific results that have not been independently documented.
